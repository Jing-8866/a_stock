## ✨ 功能特性

### 单股分析
- **四维评分系统**：估值28% + 财务32% + 技术22% + 资金18%
- **综合评分**：0-100分，给出买卖建议
- **市场归属显示**：沪市/深市/北交所

### 全市场扫描
- **智能数据源**：东方财富为主，失败自动降级新浪
- **多维度排行**：涨幅/跌幅/换手率/市盈率
- **真实数据**：覆盖5000+ A股，非演示数据

### 条件筛选
- **真实全市场数据**：直接从交易所获取实时数据
- **多条件组合**：支持任意条件组合筛选
- **结果实时刷新**：返回最新筛选结果
- **预设策略**：高股息低估值/白马成长/现金流健康等

### 自选股管理
- **本地存储**：数据持久化保存
- **立即显示**：添加股票后立即刷新显示
- **市场归属**：显示股票所属市场
- **批量查询**：支持批量获取实时行情
- **清空确认**：清空整个自选列表前需弹窗确认

### 持仓管理
- **交易明细模式**：按买入/卖出流水自动汇总持仓与盈亏，不再手工维护持仓列表
- **移动加权平均成本**：按交易时间先后顺序计算成本价，卖出只减持仓不改变成本
- **指标汇总**：总市值 / 总投入 / 总卖出 / 持仓收益（含百分比）/ 当日盈亏（含百分比）
- **当日盈亏**：综合当日交易计算，昨收缺失时自动用「现价-涨跌额」反推
- **自动加入自选**：录入交易时若股票不在自选股中会自动加入
- **展示已清仓**：可勾选展示曾买入但已清仓的股票及其历史盈亏
- **旧数据迁移**：旧版 holdings 数据自动迁移为买入流水
- **交易时间精确到秒**：可手动指定交易时间，默认当前时间

### K线分析
- **分时图**：实时价格和成交量
- **五日/日K/周K/月K**：完整的历史K线数据
- **交易点位标注**：持仓股票的交易点位显示圆点标记（B买入红/S卖出蓝/T混合黄），鼠标悬停显示按加权均价合并的交易信息
- **OHLC提示**：日/周/月走势图鼠标悬停显示开盘/收盘/最高/最低价
- **多数据源**：东方财富/新浪/腾讯

### 智能搜索
- **代码/名称搜索**：模糊匹配
- **多数据源**：东方财富/新浪/腾讯
- **最佳结果**：智能排序返回

### 报告导出（可选）
- Word/PDF 报告生成
- 包含完整的分析和评分

## 🚀 快速启动

### 前置要求
- **Node.js** 14+ （推荐 16+）
- **npm**（用于安装依赖）

### 安装与启动

```bash
# 1. 进入项目目录
cd A股选股分析工具

# 2. 安装依赖（如果还未安装）
npm install express cors

# 3. 启动智能数据桥接服务
node api-server.js
```

看到以下输出即表示启动成功：

```

║     A股数据桥接服务 v2.0                      ║

║  服务地址: http://localhost:7373              ║

╚═══════════════════════════════════════════╝
```

### 4. 打开浏览器

访问 **http://localhost:7373/index.html** 即可使用。

> 💡 也可以直接双击 `index.html` 打开，工具会自动连接本地接口。

### 5. 故障排除

如果出现中文乱码问题：
- 确保使用最新版本的 `api-server.js`（已内置编码修复）
- 检查网络连接，工具会自动降级使用备用数据源
- 重启服务：`Ctrl+C` 停止服务，重新运行 `node api-server.js`

## 📖 使用说明

### TAB 页切换
页面顶部有 5 个 TAB 页，点击即可切换：
- **📊 单股分析** — 输入股票代码进行深度体检
- **⭐ 自选股** — 管理自选股列表，查看实时行情
- **💼 持仓管理** — 录入交易明细，查看持仓盈亏
- **🔄 全市场扫描** — 涨跌幅 / 换手率排行
- **🔍 条件筛选** — 多条件组合筛选全市场

> 切换到自选股 / 持仓管理 TAB 时会自动刷新实时行情数据。

### 单股分析
1. 切换到 **📊 单股分析** TAB
2. 在输入框输入股票代码（如 `600519` 或 `sh600519`）
3. 点击 **📊 分析** 按钮
4. 查看实时行情、综合评分（0-100）、买卖建议
5. 点击 **⭐ 加入自选** 将该股加入自选列表
6. 点击 **💼 交易** 跳转到持仓管理并自动填充该股信息

**股票信息显示格式：**
```
[市场归属] | [股票代码] | [股票名称]
示例：沪市 | sh600519 | 贵州茅台
```

**评分标准：**
- ≥ 70 分 → ✅ 建议买入
- 50-69 分 → ⏳ 观望为主
- < 50 分 → ❌ 不建议

### 自选股管理
1. 切换到 **⭐ 自选股** TAB
2. 分析某只股票后点击 **⭐ 加入自选**，或直接输入代码添加
3. 查看所有自选股的实时行情（涨跌幅、现价、涨跌额）
4. 点击 **🗑️ 删除** 移除单只，或 **清空全部** 清空列表（需确认）
5. 数据自动保存在浏览器 localStorage

### 持仓管理
1. 切换到 **💼 持仓管理** TAB
2. 在输入区填写：股票代码 / 买卖类型 / 交易时间 / 价格 / 数量
   - 输入代码后下方提示「股票名称(股票代码)」
   - 交易时间精确到秒，默认当前时间
   - 可点击自选股或持仓股快速填充
3. 点击 **➕ 添加交易** 录入交易明细
4. 下方持仓列表自动汇总：
   - **持仓数量** / **成本价**（移动加权平均）/ **市值** / **持仓收益**（含百分比）
   - 点击 **📋 交易明细** 展开该股票全部交易流水（同时只展开一个）
5. 顶部汇总区显示：**总市值** / **总投入** / **总卖出** / **持仓收益** / **当日盈亏**（含百分比）
6. 勾选 **展示已清仓** 可查看已清仓股票的历史盈亏
7. 录入交易时若股票不在自选股中会自动加入

### 全市场扫描
- 切换到 **🔄 全市场扫描** TAB
- 点击 **🔄 执行扫描** 获取涨幅前20
- 点击 **📈 涨幅排行** / **📉 跌幅排行** / **💧 换手排行** 切换排序

### 条件筛选
- 切换到 **🔍 条件筛选** TAB
- 点击 **+** 添加筛选条件（字段/运算符/数值）
- 使用预设策略：**高股息低估值** / **白马成长** / **现金流健康**
- 点击 **🚀 执行筛选** 查看真实全市场筛选结果
- 支持多条件组合，数据源智能降级确保可用性

### K线分析
- 在单股分析结果区切换走势图周期：**分时** / **五日** / **日K** / **周K** / **月K**
- 鼠标悬停显示 OHLC 提示：
  - 日K：`日期（开:XX 收:XX 高:XX 低:XX）`
  - 周/月K：`日期（高:XX 低:XX）`
  - 分时：`日期 时间 价格 元`
- 持仓股票的交易点位在走势图上标注圆点：
  - **B**（红色）= 买入 / **S**（蓝色）= 卖出 / **T**（黄色）= 同日混合
  - 鼠标悬停圆点显示按加权均价合并的交易信息
- 多数据源支持，确保数据完整性

### 智能搜索
- 支持股票代码和名称模糊搜索
- 东方财富/新浪/腾讯多数据源
- 智能匹配最佳结果

## 🔌 API 接口一览

### 基础接口
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/health` | 健康检查 |
| GET | `/api/quote/:code` | 单股实时行情（含 `yesterdayClose`/`change`/`limitUp`/`limitDown`） |
| POST | `/api/quote/batch` | 批量行情查询（含 `yesterdayClose`，供当日盈亏计算） |

### 数据接口
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/kline/:code` | K线数据（分时/日/周/月），含 `open/high/low/close/volume` |
| GET | `/api/technical/:code` | 技术指标 |
| GET | `/api/finance/:code` | 财务数据 |
| GET | `/api/fundflow/:code` | 资金流向 |
| GET | `/api/news/:code` | 新闻/研报 |

### 筛选与排行
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/screener` | 真实全市场条件筛选 |
| GET | `/api/rank` | 全市场排行（涨跌幅/换手率/市盈率） |
| GET | `/api/search?q=keyword` | 智能股票搜索（代码/名称） |

### 系统接口
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/diag` | 数据源连通性诊断 |

## 注意事项

1. **中文编码问题**：已内置编码修复逻辑，如仍有乱码请重启服务
2. **数据源降级**：东方财富失败时自动降级新浪，确保数据可用性
3. **实时性**：腾讯接口数据可能存在轻微延迟，东财数据更实时
4. **股票代码格式**：支持 `600519`、`sh600519`、`SZ000001` 等格式
5. **持仓数据**：交易明细保存在浏览器 localStorage，清除浏览器数据会丢失
