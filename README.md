## ✨ 功能特性

### 单股分析
- **四维评分系统**：估值28% + 财务32% + 技术22% + 资金18%
- **综合评分**：0-100分，给出买卖建议
- **市场归属显示**：沪市/深市/北交所

### 全市场扫描
- **智能数据源**：东方财富为主，失败自动降级新浪
- **多维度排行**：涨幅/跌幅/换手率/市盈率
- **真实数据**：覆盖5000+ A股，非演示数据

### 条件筛选
- **真实全市场数据**：直接从交易所获取实时数据
- **多条件组合**：支持任意条件组合筛选
- **结果实时刷新**：返回最新筛选结果
- **预设策略**：高股息低估值/白马成长/现金流健康等

### 自选股管理
- **本地存储**：数据持久化保存
- **立即显示**：添加股票后立即刷新显示
- **市场归属**：显示股票所属市场
- **批量查询**：支持批量获取实时行情
- **清空确认**：清空整个自选列表前需弹窗确认

### 持仓管理
- **交易明细模式**：按买入/卖出流水自动汇总持仓与盈亏，不再手工维护持仓列表
- **FIFO先进先出成本**：每笔买入作为独立批次，卖出时优先扣减最早买入的批次，成本价 = 剩余批次加权平均价
- **指标汇总**：总市值 / 总投入 / 总卖出 / 持仓收益（含百分比）/ 当日盈亏（含百分比）
- **当日盈亏**：综合当日交易计算，昨收缺失时自动用「现价-涨跌额」反推
- **自动加入自选**：录入交易时若股票不在自选股中会自动加入
- **展示已清仓**：可勾选展示曾买入但已清仓的股票及其历史盈亏
- **旧数据迁移**：旧版 holdings 数据自动迁移为买入流水
- **交易时间精确到秒**：可手动指定交易时间，默认当前时间

### K线分析
- **分时图**：实时价格和成交量
- **五日/日K/周K/月K**：完整的历史K线数据
- **交易点位标注**：持仓股票的交易点位显示圆点标记（B买入红/S卖出蓝/T混合黄），鼠标悬停显示按加权均价合并的交易信息
- **OHLC提示**：日/周/月走势图鼠标悬停显示开盘/收盘/最高/最低价
- **多数据源**：东方财富/新浪/腾讯

### 资产分析
- **多周期统计**：按日/周/月/年/历史至今统计盈亏
- **历史至今**：从最早一笔交易到系统日期今天，含全部交易与K线数据
- **期初持仓**：统计周期开始前的持仓自动计入，K线最早边界昨收正确处理
- **差分计算**：逐日盈亏 = 今日总盈亏 - 昨日总盈亏，与持仓管理口径完全一致
- **日期范围显示**：周/月/年在日历选择框右侧显示具体日期范围
- **收益日历**：按日/周/月展示每日收益，支持点击展开
- **重点股票**：显示期间内贡献最大的正负收益股票
- **周期对比**：与上一周期对比盈亏变化

### 智能搜索
- **代码/名称搜索**：模糊匹配
- **多数据源**：东方财富/新浪/腾讯
- **最佳结果**：智能排序返回

## 📐 指标计算公式

> 以下公式基于代码最新逻辑整理，涉及费用的均使用**发生金额**口径（买入含费用、卖出扣费用）。

### 📊 单股分析 TAB

| 指标 | 公式 | 说明 |
|------|------|------|
| 综合评分 | `估值×28% + 财务×32% + 技术×22% + 资金×18%` | 四维加权，0-100分 |
| 评分建议 | ≥70 建议买入 / 50-69 观望 / <50 不建议 | — |

### ⭐ 自选股 TAB

| 指标 | 公式 | 说明 |
|------|------|------|
| 涨跌额 | `现价 - 昨收` | 元 |
| 涨跌幅 | `(现价 - 昨收) / 昨收 × 100%` | 百分比 |
| 涨停价 / 跌停价 | 行情接口直接返回 | — |

### 💼 持仓管理 TAB

**基础量定义：**

| 量 | 定义 |
|----|------|
| 买入发生金额 | `买入价格 × 买入数量 + 买入费用` |
| 卖出发生金额 | `卖出价格 × 卖出数量 - 卖出费用` |
| 持仓数量 | `Σ买入数量 - Σ卖出数量` |
| FIFO 成本价 | 卖出时优先扣减最早买入批次，成本价 = 剩余批次加权平均价 |

**单股指标：**

| 指标 | 公式 |
|------|------|
| 持仓市值 | `现价 × 持仓数量` |
| 持仓收益 | `持仓市值 + Σ卖出发生金额 - Σ买入发生金额` |
| 持仓收益率 | `持仓收益 / Σ买入发生金额 × 100%` |
| 当日盈亏 | `(现价 - 昨收) × 持仓数量 + (当日卖出发生金额 - 昨收 × 当日卖出数量) - (当日买入发生金额 - 昨收 × 当日买入数量)` |
| 当日盈亏率 | `当日盈亏 / (昨收 × 持仓数量 + 昨收 × 当日买入数量) × 100%` |

**汇总指标：**

| 指标 | 公式 |
|------|------|
| 总市值 | `Σ(现价 × 持仓数量)` |
| 总投入 | `Σ买入发生金额` |
| 总卖出 | `Σ卖出发生金额` |
| 总持仓收益 | `Σ单股持仓收益` |
| 总当日盈亏 | `Σ单股当日盈亏` |

> 现价、昨收来自 `/api/quote/batch` 实时行情接口。昨收缺失时用 `现价 - 涨跌额` 反推。

### 🌐 全市场扫描 TAB

| 指标 | 公式 | 说明 |
|------|------|------|
| 涨跌幅 | `(现价 - 昨收) / 昨收 × 100%` | 涨幅/跌幅排行 |
| 换手率 | 行情接口直接返回 | 换手排行 |
| 市盈率 | 行情接口直接返回 | PE排行 |

### 🎯 条件筛选 TAB

多条件组合筛选，每条条件为 `字段 + 运算符 + 数值`，全部条件 AND 组合。

预设策略：高股息低估值 / 白马成长 / 现金流健康。

### 📈 资产分析 TAB

**统计周期与日期范围：**

| 周期 | 起始日期 | 结束日期 | 日期范围显示 |
|------|----------|----------|-------------|
| 日 | 选择日期 | 选择日期 | `日期` |
| 周 | 选择日期所在周一 | 当周五 | `周一 ~ 周五` |
| 月 | 选择月1日 | 选择月最后一天 | `月1日 ~ 月末` |
| 年 | 选择年1月1日 | 选择年12月31日 | `年1月1日 ~ 12月31日` |
| 历史至今 | 最早一笔交易日期 | **系统日期今天** | `最早交易 ~ 今天` |

**期初持仓（periodStart 之前的交易累计）：**

| 量 | 定义 |
|----|------|
| 期初持仓数量 | `Σ(periodStart前买入数量) - Σ(periodStart前卖出数量)` |
| 期初买入金额 | `Σ(periodStart前买入发生金额)` |
| 期初卖出金额 | `Σ(periodStart前卖出发生金额)` |
| 期初前最后收盘价 | K线中 `d < periodStart` 的最后一个有效收盘价 |
| 期初市值 | `期初前最后收盘价 × 期初持仓数量` |
| 期初总盈亏 | `期初市值 + 期初卖出金额 - 期初买入金额` |

**逐日计算（差分方式，从期初值开始累加）：**

| 量 | 公式 |
|----|------|
| 累计持仓(d) | `期初持仓 + Σ(期间内 time≤d 的买入数量) - Σ(期间内 time≤d 的卖出数量)` |
| 累计买入金额(d) | `期初买入金额 + Σ(期间内 time≤d 的买入发生金额)` |
| 累计卖出金额(d) | `期初卖出金额 + Σ(期间内 time≤d 的卖出发生金额)` |
| 当日收盘价(d) | K线收盘价；停牌时取最近有效收盘价（含期间前数据） |
| 总盈亏(d) | `当日收盘价(d) × 累计持仓(d) + 累计卖出金额(d) - 累计买入金额(d)` |
| 当日盈亏(d) | `总盈亏(d) - 总盈亏(d-1)`，首日基准为期初总盈亏 |

> 当日盈亏差分公式数学等价于持仓管理的当日盈亏公式：`(收盘价-昨收)×持仓 + (当日卖出-昨收×卖量) - (当日买入-昨收×买量)`，且自动处理期初持仓与K线边界昨收。

**期间汇总指标：**

| 指标 | 公式 | 说明 |
|------|------|------|
| 期间盈亏 | `Σ(期间内每日当日盈亏)` = `总盈亏(end) - 总盈亏(start-1)` | 含费用 |
| 累计盈亏 | `Σ(从days[0]到end的每日当日盈亏)` | 含费用 |
| 买卖笔数 | 期间内交易笔数 | 买入+卖出 |
| 重点股票 | 期间内贡献最大的正/负收益股票 | 按盈亏排序 |

> K线收盘价来自 `/api/kline` 接口（腾讯→东财→新浪降级）；费用通过发生金额自动计入盈亏。

## 📖 使用说明

### TAB 页切换
页面顶部有 6 个 TAB 页，点击即可切换：
- **📊 单股分析** — 输入股票代码进行深度体检
- **⭐ 自选股** — 管理自选股列表，查看实时行情
- **💼 持仓管理** — 录入交易明细，查看持仓盈亏
- **🌐 全市场扫描** — 涨跌幅 / 换手率排行
- **🎯 条件筛选** — 多条件组合筛选全市场
- **📈 资产分析** — 按日/周/月/年统计盈亏与重点股票

> 切换到自选股 / 持仓管理 / 资产分析 TAB 时会自动刷新实时行情数据。

### 单股分析
1. 切换到 **📊 单股分析** TAB
2. 在输入框输入股票代码（如 `600519` 或 `sh600519`）
3. 点击 **📊 分析** 按钮
4. 查看实时行情、综合评分（0-100）、买卖建议
5. 点击 **⭐ 加入自选** 将该股加入自选列表
6. 点击 **💼 交易** 跳转到持仓管理并自动填充该股信息

**股票信息显示格式：**
```
[市场归属] | [股票代码] | [股票名称]
示例：沪市 | sh600519 | 贵州茅台
```

**评分标准：**
- ≥ 70 分 → ✅ 建议买入
- 50-69 分 → ⏳ 观望为主
- < 50 分 → ❌ 不建议

### 自选股管理
1. 切换到 **⭐ 自选股** TAB
2. 分析某只股票后点击 **⭐ 加入自选**，或直接输入代码添加
3. 查看所有自选股的实时行情（涨跌幅、现价、涨跌额）
4. 点击 **🗑️ 删除** 移除单只，或 **清空全部** 清空列表（需确认）
5. 数据自动保存在浏览器 localStorage

### 持仓管理
1. 切换到 **💼 持仓管理** TAB
2. 在输入区填写：股票代码 / 买卖类型 / 交易时间 / 价格 / 数量
   - 输入代码后下方提示「股票名称(股票代码)」
   - 交易时间精确到秒，默认当前时间
   - 可点击自选股或持仓股快速填充
3. 点击 **➕ 添加交易** 录入交易明细
4. 下方持仓列表自动汇总：
   - **持仓数量** / **成本价**（FIFO先进先出）/ **市值** / **持仓收益**（含百分比）
   - 点击 **📋 交易明细** 展开该股票全部交易流水（同时只展开一个）
5. 顶部汇总区显示：**总市值** / **总投入** / **总卖出** / **持仓收益** / **当日盈亏**（含百分比）
6. 勾选 **展示已清仓** 可查看已清仓股票的历史盈亏
7. 录入交易时若股票不在自选股中会自动加入

### 全市场扫描
- 切换到 **🌐 全市场扫描** TAB
- 点击 **🔄 执行扫描** 获取涨幅前20
- 点击 **📈 涨幅排行** / **📉 跌幅排行** / **💧 换手排行** 切换排序

### 条件筛选
- 切换到 **🎯 条件筛选** TAB
- 点击 **+** 添加筛选条件（字段/运算符/数值）
- 使用预设策略：**高股息低估值** / **白马成长** / **现金流健康**
- 点击 **🚀 执行筛选** 查看真实全市场筛选结果
- 支持多条件组合，数据源智能降级确保可用性

### 资产分析
1. 切换到 **📈 资产分析** TAB
2. 选择统计周期：日 / 周 / 月 / 年 / 历史至今
3. 查看期间盈亏、累计盈亏、买卖笔数
4. 查看每日/每周/每月收益走势 + 收益日历
5. 查看重点股票（正收益最高 / 负收益最大）
   - **按日分析**：展示当日持有（包含当日已清仓）的所有股票
   - **其他周期**：展示期间内有盈亏的股票

### K线分析
- 在单股分析结果区切换走势图周期：**分时** / **五日** / **日K** / **周K** / **月K**
- 鼠标悬停显示 OHLC 提示：
  - 日K：`日期（收:XX 开:XX 高:XX 低:XX）`
  - 周/月K：`日期（高:XX 低:XX）`
  - 分时：`日期 时间 价格 元`
- 持仓股票的交易点位在走势图上标注圆点：
  - **B**（红色）= 买入 / **S**（蓝色）= 卖出 / **T**（黄色）= 同日混合
  - 鼠标悬停圆点显示按加权均价合并的交易信息
- 多数据源支持，确保数据完整性

### 智能搜索
- 支持股票代码和名称模糊搜索
- 东方财富/新浪/腾讯多数据源
- 智能匹配最佳结果

## 技术栈

| 层级 | 技术 |

## 注意事项

1. **中文编码问题**：已内置编码修复逻辑，如仍有乱码请重启服务
2. **数据源降级**：东方财富失败时自动降级新浪，确保数据可用性
3. **实时性**：腾讯接口数据可能存在轻微延迟，东财数据更实时
4. **股票代码格式**：支持 `600519`、`sh600519`、`SZ000001` 等格式
5. **持仓数据**：交易明细保存在浏览器 localStorage，清除浏览器数据会丢失
6. **资产分析**：按日分析时重点股票展示当日持有（包含当日已清仓）的所有股票
