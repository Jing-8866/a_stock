## 🚀 快速启动

### 前置要求
- **Node.js** 14+ （推荐 16+）
- **npm**（用于安装依赖）

### 安装与启动

```bash
# 1. 进入项目目录
cd A股选股分析工具

# 2. 安装依赖（如果还未安装）
npm install express cors

# 3. 启动智能数据桥接服务
node api-server.js
```

看到以下输出即表示启动成功：

```
╔═══════════════════════════════════════════╗
║     A股数据桥接服务 v2.0                      ║
╠═══════════════════════════════════════════╣
║  服务地址: http://localhost:7373              ║
║  分析工具: http://localhost:7373/A股分析工具_实时版.html ║
║  API文档:  http://localhost:7373/api/health              ║
╚═══════════════════════════════════════════╝
```

### 4. 打开浏览器

访问 **http://localhost:7373/** 即可使用。

> 💡 也可以直接双击 `A股分析工具_实时版.html` 打开，工具会自动连接本地接口。

### 5. 故障排除

如果出现中文乱码问题：
- 确保使用最新版本的 `api-server.js`（已内置编码修复）
- 检查网络连接，工具会自动降级使用备用数据源
- 重启服务：`Ctrl+C` 停止服务，重新运行 `node api-server.js`

## 📖 使用说明

### 单股分析
1. 在输入框输入股票代码（如 `600519` 或 `sh600519`）
2. 点击 **📊 分析** 按钮
3. 查看实时行情、综合评分（0-100）、买卖建议

**股票信息显示格式：**
```
[市场归属] | [股票代码] | [股票名称]
示例：沪市 | sh600519 | 贵州茅台
```

**评分标准：**
- ≥ 70 分 → ✅ 建议买入
- 50-69 分 → ⏳ 观望为主
- < 50 分 → ❌ 不建议

### 全市场扫描
- 点击 **🔄 执行扫描** 获取涨幅前20
- 点击 **📈 涨幅排行** / **📉 跌幅排行** / **💧 换手排行** 切换排序

### 条件筛选（改进版）
- 点击 **+** 添加筛选条件（字段/运算符/数值）
- 使用预设策略：**高股息低估值** / **白马成长** / **现金流健康**
- 点击 **🚀 执行筛选** 查看真实全市场筛选结果
- 支持多条件组合，数据源智能降级确保可用性

### 自选股管理（改进版）
- 分析某只股票后点击 **⭐ 加入自选**
- 在自选股面板查看所有自选股的实时行情
- **新增**：立即显示加入的股票，无需手动刷新
- **新增**：显示市场归属（沪市/深市/北交所）
- **新增**：显示股票添加时间
- 支持删除单只或清空全部

### K线分析
- 支持分时图、日K、周K、月K线
- 多数据源支持，确保数据完整性
- 显示涨跌幅、成交量等关键指标

### 智能搜索
- 支持股票代码和名称模糊搜索
- 东方财富/新浪/腾讯多数据源
- 智能匹配最佳结果

### 报告导出（可选）
如需生成 Word/PDF 报告：
```bash
pip install python-docx requests
python gen_docx.py sh600519
```


## 注意事项

1. **中文编码问题**：已内置编码修复逻辑，如仍有乱码请重启服务
2. **数据源降级**：东方财富失败时自动降级新浪，确保数据可用性
3. **实时性**：腾讯接口数据可能存在轻微延迟，东财数据更实时
4. **股票代码格式**：支持 `600519`、`sh600519`、`SZ000001` 等格式

## 🔌 API 接口一览

### 基础接口
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/health` | 健康检查 |
| GET | `/api/quote/:code` | 单股实时行情 |
| POST | `/api/quote/batch` | 批量行情查询 |

### 数据接口
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/kline/:code` | K线数据（分时/日/周/月） |
| GET | `/api/technical/:code` | 技术指标 |
| GET | `/api/finance/:code` | 财务数据 |
| GET | `/api/fundflow/:code` | 资金流向 |
| GET | `/api/news/:code` | 新闻/研报 |

### 筛选与排行
| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/screener` | 真实全市场条件筛选 |
| GET | `/api/rank` | 全市场排行（涨跌幅/换手率/市盈率） |
| GET | `/api/search?q=keyword` | 智能股票搜索（代码/名称） |

### 系统接口
| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/api/diag` | 数据源连通性诊断 |
